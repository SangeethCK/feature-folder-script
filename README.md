# feature-folder-script

Generator for a feature-based Clean Architecture in Next.js (App Router, TypeScript, Redux Toolkit + RTK Query, Tailwind, Zod, React Hook Form, Vitest).

## Usage

```bash
# New project
npx github:SangeethCK/feature-folder-script my-app --create

# Existing Next.js project (run inside the project folder)
npx github:SangeethCK/feature-folder-script

# Add a feature
npx github:SangeethCK/feature-folder-script --feature orders
```

Run with `--help` for all options. Use `--dry-run` to preview changes.
